# 세차관리

출장 세차(내부·외부) 고객 관리용 모바일 웹앱입니다.

- 고객·차량 관리 (차량번호, 연락처, 주차 위치, 기본 금액, 정기 주기)
- 세차 예약·일정 (예정 / 완료 / 취소)
- 입금 관리 (입금일, 방법, 월별 정산, 미입금 목록)
- 문자 자동 작성 (예약 안내, 전날 알림, 세차 완료, 입금 요청 등)

## 저장 방식
- 기록은 Supabase(위스키 앱 DRAVÉ와 같은 프로젝트)의 `carwash_` 표에 저장됩니다.
- 이메일로 가입한 뒤 관리자가 승인한 계정만 기록을 보고 고칠 수 있습니다. 표 구조와 잠금 규칙은 `supabase.sql`에 있습니다.
- 관리자는 앱의 **문자·설정 → 관리**에서 가입 승인, 백업 받기·불러오기를 할 수 있습니다.
